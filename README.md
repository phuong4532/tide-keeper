**Tide Keeper** is a lighthouse defence roguelite for the desktop browser. Sweep the beam with the mouse, focus it into a laser, and burn back the sea through 12 waves in 3 tides, two Kraken Queen bosses, relics and upgrades. Win by holding the light through wave 12; lose when the hull reaches 0.

## Run it

```sh
node serve.ts --port 8765
# then open http://localhost:8765/index.html in desktop Chrome
```

Mouse aims, SPACE or click focuses, Q / E / R cast powers, P pauses, M mutes.
